# Elite Fitness Gym

A premium, modern, production-ready Gym & Fitness website designed for high conversion, performance, SEO, and responsive user experience.

## Tech Stack

* Next.js 15
* React
* TypeScript
* Tailwind CSS
* ShadCN UI
* Framer Motion
* Supabase
* Docker

## Key Features

* Premium responsive fitness website
* Membership plans
* Fitness classes and services
* Personal trainer profiles
* BMI Calculator
* Before & After transformations
* Client reviews and ratings
* Photo and video gallery
* Blog and FAQ sections
* Contact and enquiry system
* WhatsApp enquiry integration
* Google Maps integration
* Newsletter system
* Secure admin dashboard
* Trainer and membership management
* Blog and gallery management
* Review and enquiry management
* SEO management
* Analytics dashboard

## SEO

* Dynamic metadata
* Open Graph and Twitter Cards
* JSON-LD structured data

* FAQ Schema
* Review Schema
* XML Sitemap
* robots.txt
* Canonical URLs
* Optimized images
* Semantic HTML
* Internal linking
* Local SEO structure

## Performance

* Image optimization
* Lazy loading
* Code splitting
* Caching
* Responsive design
* Core Web Vitals optimization
* Mobile-first approach

## Admin Dashboard

The project includes a secure admin dashboard for managing:

* Members
* Enquiries
* Trainers
* Membership Plans
* Blog Posts
* Gallery
* Reviews
* Website Content
* SEO Settings
* Analytics
* Contact Information

## Database

Powered by Supabase with structured tables for:

* Users
* Enquiries
* Reviews
* Ratings
* Blog
* Gallery
* Membership Plans
* Trainers
* Settings

## Project Structure

The application follows a reusable component-based architecture with separate sections for UI components, pages, API functionality, database integration, and administrative features.

## Development

```bash
npm install
npm run dev
```

Open the development server in your browser to view the application.

## Production

The project is structured for production deployment and can be containerized using Docker.
